# Отчёт о нагрузке для DeepSeek Harness (DSH)

> **Рабочее время и использование токенов на одной картине** — по **датам** и **рабочим пространствам**: календарная тепловая карта, анализ по часам, доля рабочих пространств, использование моделей и **автономный HTML-отчёт в один клик**, который можно сразу отправить клиенту.

## Что это

DSH (DeepSeek Harness) показывает статистику только текущей сессии. Плагин DSH «Отчёт о нагрузке» добавляет общий взгляд по всем сессиям, проектам и времени: как распределяются рабочее время и использование токенов по датам и рабочим пространствам, в какие часы вы продуктивнее, какие модели расходуют токены и сколько это стоит.

Помимо использования токенов видно саму работу: активное время, активные дни и раунды. Каждое рабочее пространство и каждая дата считаются по одним правилам, поэтому все экраны и экспортируемый отчёт дают согласованные цифры. Интерфейс многоязычный: панель, HTML-отчёт, ИИ-профиль и диалоги синхронизации следуют языку DSH.

## Возможности

- **Нагрузка и токены в одном представлении.** Активное время = время модели + время инструментов, ожидание пользователя исключено; рядом — токены, активные дни, раунды и скорость вывода.
- **Разрезы по датам, рабочим пространствам, моделям и сессиям**: ежедневная динамика, календарная тепловая карта по всей истории, анализ активности по часам суток, доля рабочих пространств, древовидная карта моделей и топ-сессии.
- **Скорость модели, TTFT и оценка стоимости** по официальным публичным ценам: числа показываются только для моделей с официальной ценой, без выдуманных значений.
- **Автономный HTML-отчёт, который можно отправить клиенту**: один файл со встроенными CSS и SVG, без скриптов и внешних ресурсов, светлая и тёмная темы, анонимизация названий рабочих пространств и заголовков сессий по запросу.
- **ИИ-профиль пользователя** — только по ручному нажатию и только по агрегатам: без диалогов, заголовков и путей.
- **Синхронизация между устройствами**: Tencent COS, GitHub, Gitea или общая папка; по умолчанию выключена.
- **8 языков интерфейса** — панель, HTML-отчёт, ИИ-профиль и диалоги синхронизации следуют языку DSH и переключаются на лету.
- **Только официальные интерфейсы и предсказуемые цифры**: по умолчанию никаких внешних запросов, вся статистика остаётся на вашем компьютере; 1738 офлайн-тестов проверяют расчёты, отчёт, синхронизацию и все 8 языков.

## Установка

```bash
# из npm
dsh plugin add dsh-workload-report

# или напрямую с GitHub
dsh plugin --profile web add github:tableau-China/dsh-workload-report#main
```

После установки перезапустите Web-профиль DSH: вход появится **внизу боковой панели** — «Отчёт о нагрузке». Клиентский бандл уже собран: при установке из npm или GitHub локальная сборка не требуется.

Требования: DSH `0.2.x` (включая `alpha`-версии) и Node.js ≥ 22. Текущая версия — 2.5.0. Удаление: `dsh plugin --profile web remove dsh-workload-report`.

## Первый запуск

При первом запуске плагин один раз читает историю прошлых сессий через официальные интерфейсы; пока это происходит, данные приходят постепенно и помечены флагом `indexing: true`.

После перезапуска используется сохранённый индекс, поэтому повторного чтения истории не требуется. Файл индекса в `<DSH_HOME>/workload-report/` можно безопасно удалить — он пересоберётся автоматически.

## Приватность

Вся статистика остаётся на вашем компьютере. Плагин регистрирует только HTTP-маршруты для чтения: по умолчанию нет внешних запросов, телеметрии и сбора пользовательского контента. ИИ-профиль вызывает модель только после нажатия кнопки и отправляет лишь агрегаты — без диалогов, заголовков и путей; необязательный индикатор баланса выключен по умолчанию.
